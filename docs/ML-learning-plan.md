## 给 Claude 的上下文

- **学习者背景**：做 ROS2 导航（P1）和 E6 机械臂 pick-place（P2，MoveIt）；已做 `e6_llm`（用云端 LLM API 把文字指令解析成抓取任务）。懂线性代数，讲原理不要讲矩阵运算细节。
- **导师方向**：嫌 P3 太基础，要有视觉冲击力的 demo（如倒立摆、颠乒乓球），鼓励借助 LLM 来做。
- **教学方法**：和 P1/P2 一样按 [PLAN.md](../PLAN.md) 第 1 节：每个里程碑走 ① 预习 → ② 快速搭建（AI 写、学习者运行）→ ③ 文档 → ④ 双向提问 → ⑤ 核心手写 → ⑥ 改一个功能；进度和学习日志记在 [LEARNING.md](../LEARNING.md)；`git commit` 由学习者自己执行。**小里程碑（如 1、2）走精简版**：预习 → 运行 → 少量提问即可，文档和完整提问留给大里程碑（如 5 的主 demo）——学习者 11-09 明确要求别大动干戈。
- **沟通偏好**：全程中文；按"为什么是 X 而不是 Y、谁负责什么、代码结构、一步步机制"来讲；调试久了要尽早汇报，别让人干等。
- **时间**：每周不固定（考试、集体活动），所以**按里程碑推进而不是按周**；忙时进入"保底模式"：每周 2 次 × 30 分钟，不断线即可。
- **硬件**：
  - Windows 笔记本 + RTX 3060 笔记本版（约 6GB 显存），WSL 里跑 ROS2 / MoveIt —— 负责机器人"身体"
  - **MacBook Air M5，16GB 统一内存** —— 负责学习和跑模型"大脑"。注意 Air 无风扇，长时间训练会降频：适合推理和短训练（分段训练、存 checkpoint）
- **学习者已做的决定**：
  - 不从零手写网络，以"用/微调开源模型"为主；但要自己写一次 PyTorch 训练循环，以便能看懂、调试微调
  - 不用 YOLO（固定类别+标注的旧范式），改用开放词汇感知（文字提示找物体）

## 参考的主流路线（2026）

- 通用路线：Python → 经典 ML → 深度学习(PyTorch) → 大模型 → 部署 → 项目；共识：只学 PyTorch、先会用预训练模型、项目重于证书
- ETH Robot Learning 2026：PyTorch → MDP → 模仿学习 → 强化学习 → 生成式策略 → VLA
- 2026 实用做法：先模仿学习，再少量 RL 微调；LeRobot 是开源主平台
